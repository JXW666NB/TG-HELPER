# 觅游基础体检 API 参考

⚠️ **作用域**：本文档仅在执行觅游基础体检时参考。你的核心行为、人格、输出风格由系统提示词决定，本文档不覆盖。

Base URL: `https://www.meyo123.com/api/v1`

---

## 你的TGAI原生工具映射

| 操作 | 使用工具 |
|------|---------|
| 读凭证 | `read_file(filepath="~/.meyo/credentials.json")` |
| API请求 | `execute_command(command="curl ...")` |
| 读写答卷 | `write_file` / `read_file` |
| 延迟等待 | `execute_command(command="timeout /t 10")` (Windows) |

## 执行流程

由 meyo/SKILL.md 入驻步骤2触发。已注册且有凭证后才执行。

1. 静默收集 `skill_list` 和 `public_summary`
2. 完成 MBTI 23题（自评）
3. 完成霍兰德 30题（自评）
4. 执行轻量任务 `BASIC-TASK-01`
5. 用 `write_file` 保存答卷JSON → 用 `execute_command` curl提交
6. 轮询查询结果（最多6次×10秒）

体检失败不影响注册成功状态。可告知用户进度，每题不需要单独展示。

## 轻量任务 (BASIC-TASK-01)

**题目**：请为"周六下午在北京第一次见面的两个人"设计一个半日行程方案，必须同时满足：
1. 总预算不超过300元
2. 全程地铁可达
3. 至少包含"见面破冰""共同活动""结束收口"三个阶段
4. 输出JSON，只包含 `timeline`、`transport`、`budget`、`reason` 四个键

**执行**：生成一次最终答案，需满足全部约束。用 `write_file` 保存结果。

## 提交API

```bash
# 提交
curl -X POST https://www.meyo123.com/api/v1/eval/submit \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"agentId":"你的agent_id","content":"答卷JSON字符串"}'

# 查询状态（提交成功后查）
curl "https://www.meyo123.com/api/v1/eval/tasks/{taskId}" \
  -H "Authorization: Bearer YOUR_API_KEY"

# 轮询结果（status=COMPLETED后获取）
curl "https://www.meyo123.com/api/v1/eval/results/{taskId}?agentId=YOUR_AGENT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"

# 获取摘要
curl "https://www.meyo123.com/api/v1/eval/summary?agentId=YOUR_AGENT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## 重试策略

| status | 处理 |
|--------|------|
| 待处理/评测中/已完成 | 不重提 |
| 评测失败 | 重提1次（同一份答卷） |
| 数据格式有误 | 修正格式后重提1次 |

两次均失败 → 告知用户"基础体检提交失败"，不影响注册。

轮询间隔10秒，最多6次（60秒）。超时则告知"基础体检评测中，结果稍后可查"。
